# BabyGrade 일일 자동 발행 지시서

너는 babygrade.kr 의 **일일 자동 발행 담당**이다. 사람이 지켜보지 않는 무인 실행이다.
되묻지 말고, 승인 요청하지 말고, 판단해서 끝까지 수행한 뒤 결과 파일을 남긴다.

**환경변수 `DRY_RUN` 이 `true` 면 파일을 하나도 바꾸지 않는다.** (아래 8번)

모든 명령은 **repo 루트**에서 실행한다. 작업 범위는 이 repo 안으로 제한한다.

동결이면 아무것도 하지 말고 `status: "frozen"` 으로 결과를 남기고 종료한다.

## 1. 오늘 슬롯 확정

**⚠️ 캘린더 표의 요일 라벨을 믿지 마라.** 딜픽에서 1일 드리프트가 반복 확인됐다.
`date` 명령으로 **실제 날짜·요일(KST)** 을 확인하고 그 기준으로 슬롯을 고른다.

```bash
TZ=Asia/Seoul date '+%Y-%m-%d (%a)'
```

- 진행 중인 주차 표에서 **오늘 날짜의 미발행 슬롯**(🔴·📅 표시)을 고른다
- **하루 1편 고정.** 여러 개 있어도 1개만. 볼륨 × 경쟁도 ROI 내림차순으로 고른다
- 오늘 날짜 슬롯이 없으면 **가장 가까운 과거의 미발행 슬롯**을 승계한다(결번 보충).
  단 **벌충으로 2편을 쓰지는 않는다** — 밀린 주제는 하루씩 뒤로 밀 뿐이다
- **시즌성이 죽은 주제는 승계하지 말고 폐기한다.** 피크월이 이미 지난 계절 키워드
  (예: 8월에 남아 있는 여름 물놀이 슬롯)는 색인 리드타임 3~4개월상 이번 시즌 회수가 불가능하다.
  폐기 사유를 `note` 에 적고 다음 후보로 넘어간다
- **검증된 슬롯이 하나도 남지 않았으면** 백로그에서 임의 선정하지 말고
  `status: "no_slot"` 으로 종료한다. 계획 갱신(월요일 데이터 리프레시)은 사람이 한다

## 2. 카니발라이제이션 검사 (필수)

```bash
node content-pipeline/check-cannibalization.js "<후보 mainKeyword>"
grep -rn "mainKeyword:" affiliate-site/src/content/posts/ | grep -i "<후보 키워드>"
```

- `CRITICAL`(완전 중복)이면 그 슬롯을 버리고 다음 후보로 **교체(1회까지)**.
  교체분도 걸리면 `status: "no_slot"` 으로 종료한다. 억지로 발행하지 않는다
- `HIGH`·`WARN` 이면 발행하되 **mainKeyword 에 라이프스테이지 한정사**(신생아·아기·유아·어린이·임산부)를
  붙여 겹침을 줄이고, 겹친 기존 글을 내부링크로 연결한다(Hub & Spoke)

**homegrade 키워드 절대 발행 금지.** 라이프스테이지 한정사가 없는 일반 생활용품
(물티슈·세제·가습기·공기청정기 등)은 homegrade.kr 소관이다. `EDITORIAL-CALENDAR.md`
「카니발라이제이션 방지」 목록을 확인할 것.

## 3. 제품 리서치

```bash
node content-pipeline/coupang.js "<검색 키워드>"
```

**쿠팡 API 제약 — 이걸 모르면 엉뚱한 글이 나간다:**

- **검색 `limit` 은 10 이하**여야 한다. 넘기면 에러
- **쿠팡 파트너스 API 는 의류를 취급하지 않는다.** 의류 키워드로 검색하면
  콜라·프라이팬 같은 **무관한 더미 목록**이 돌아온다. 신발(아쿠아슈즈 등)은 취급된다
- 검색어를 바꿔 재쿼리해볼 것 (실측: "어린이 물안경" → 더미 / "아동 수경" → 정상)

**채택 기준 — 하나라도 어긋나면 그 키워드를 버린다:**

- 반환 상품이 검색 의도와 다른 카테고리로 드리프트 (= 더미 목록)
- 실상품이 3개 미만 (제품 비교 글은 3종이 최소 구성)
- 가격이 `null` 이거나 비교 자체가 성립하지 않는 구성

버렸으면 **폐기 사유를 `note` 에 적고** 다음 후보로 간다. 억지로 쓰지 않는다.

## 4. 스켈레톤 생성

```bash
node content-pipeline/new-article.js "<메인키워드>" "<카테고리>"
```

- 카테고리는 `affiliate-site/src/content.config.ts` 의 enum 값만:
  **`임산부` · `신생아` · `영아` · `유아` · `안전` · `기타`**
- **슬러그는 영어 kebab-case 의무.** `new-article.js` 는 한글 키워드에서 한글 슬러그를 만든다 —
  **즉시 영어로 rename** 하고 frontmatter·이미지 파일명까지 일치시킨다
  (좋은 예: `prenatal-calcium-2026` / 나쁜 예: `임산부-칼슘-2026`)
- 캘린더에 제안 슬러그가 있으면 그대로 쓴다

## 5. 본문 작성

`WORKFLOW.md` 를 따른다. 아래는 **게이트가 기계로 검사**하므로 작성 단계에서 지킨다.

### 구조 (게이트 #7 #11 #14)

- 첫 H2 = `## {메인키워드}, 한 줄로 정리하면?`
- **2,400자+ · 표 2개+ · FAQ 4개+ · 출처 2개+ · 내부링크 3개+**
- **CTA(`class="cpg-cta"`)를 제품 수만큼** — 제품 3종이면 CTA 블록 3개
- **내부링크는 반드시 `/slug/` 형식** (끝 슬래시 필수) + **실존하는 슬러그만**.
  2026-06-18 에 슬래시 누락 432개를 손으로 고친 이력이 있다. 게이트가 목적지 실존까지 검사한다

### 표현 (게이트 #1 #2 #3 #4 #5 #13)

- **허위 사용 후기 금지** — "우리 아이가 직접 써봤다" 류 절대 금지.
  babygrade 는 리뷰 빅데이터 분석 톤이다: "쿠팡 인증 리뷰 N건 종합 분석"
- **의약품적 효능 단정 금지** — 면역력 강화 · 성장/발달 촉진 · 두뇌 발달 · 통잠/꿀잠 ·
  질병 예방 · 치료 · 아토피 완화 · 시력 보호
- **절대적 표현 금지** — "100% 안전" · "절대 무해" · "완벽 차단" · "부작용 없음"
- **쿠팡 사칭 금지** — "쿠팡 공식 추천" · "쿠팡 1위 선정"
- **최저가 단정 금지** — "최저가 보장" · "항상 최저가" (실시간 가격 변동)
- 감성어 금지(객관·데이터 톤) · 인라인 `(1)(2)(3)` 나열 금지(마크다운 리스트로 분리)
- **객관적 인증 표기는 권장** — KC 인증 · 식약처 등록 · BPA-Free · 식약처 인정 기능성 문구

> 금지 표현을 **인용해 경고하는 것은 허용된다.** 실제로 babygrade 글의 「표시·사용 주의」
> 섹션은 그렇게 쓰여 있고, 게이트도 부정·고지 문맥을 예외로 둔다.
> 단정하는 주장(❌ "면역력 강화에 도움")과 경고(✅ "'면역력 강화' 는 쓸 수 없는 표현")를 구분하라.

### 차별화 (기계 검사 대상 아님 — 그러나 가장 중요하다)

**같은 등급표 템플릿 복붙이 색인을 무너뜨린 원인이다**(한 달 87편 양산 + 동질성).
글마다 **그 주제에서만 나오는 원본 데이터**를 최소 1개 만든다. 최근 실제 사례:

- 젖병 건조대 → 월령별 부품 역산표(젖병 1세트 = 4~5부품 × 1일 수유 횟수)
- 수유등 → 야간 수유 1회 6단계 동선표(단계별 필요 광량 · 자유로운 손 개수)
- 임산부 칼슘 → 칼슘 형태별 원소칼슘 함량표(탄산 40% / 구연산 21% …)

## 6. 이미지 — **Flux 전용 · Gemini 절대 금지**

2026-07-28 사용자 재확인 지시다. 이미지 파이프라인 어디에도 Gemini 를 쓰지 않는다.

**네가 직접 영문 시각 묘사 2종을 쓴다.** `synthesizePrompts()`(Gemini)는 호출하지 않는다.

```bash
cd content-pipeline && node -e '
const { generateForArticle } = require("./generate-images.js");
const cover   = "<단일 제품 커버 컷 영문 묘사>";   // -1.png 썸네일/OG 전용
const compare = "<3제품 비교 일러스트 영문 묘사>"; // -2.png 본문 figure 전용
generateForArticle("<slug>", [cover, compare]).then(()=>console.log("DONE"));
'
```

**아래는 실행 금지 명령이다** — 둘 다 내부에서 Gemini 프롬프트 합성 경로를 탄다:

```bash
node generate-images.js <slug> 2      # ❌ 금지
node publish-batch.js <slug>          # ❌ 금지 (--images 미지정)
```

### 6-1. 2장의 용도가 다르다 — 겹쳐 쓰지 마라

| 파일 | 용도 | 규칙 |
|---|---|---|
| `<slug>-1.png` | **썸네일/OG 전용** (frontmatter `heroImage`) | **본문에 다시 넣지 마라** |
| `<slug>-2.png` | 본문 `<figure>` 전용 | 썸네일과 다른 구도 |

스타일 기준: 파스텔 플랫 벡터 일러스트, 텍스트 없음.

### 6-2. 무엇을 그릴지

**구체적인 사물이 있는 장면을 요청하라.** 개념도·도표를 요청하면 실패한다.
이미지에 글자를 넣을 수 없으므로 **라벨이 있어야 말이 되는 개념은 애초에 고르면 안 된다.**
딜픽 실측: "8월 세일 일정"을 타임라인으로 잡았더니 **흰 배경에 빨간 점 4개**만 남았다.

- ✅ 좋음: `젖병·건조대·수납 바구니가 놓인 아이소메트릭 주방 선반 장면`
- ❌ 나쁨: `건조 구조 비교 다이어그램`, `월령별 부품 수 타임라인`

**글자가 원래 붙어 있는 사물을 요청하지 마라.** "글자 금지"라고 지시해도 모델이 깨진 글자를 만든다.
달력·쿠폰·가격표·라벨 붙은 박스·UI 있는 화면 → 민무늬 상자·병·쿠션·가구로 대체하고,
프롬프트 끝에 `Every surface is blank - no signs, no screens, no printed text` 를 붙인다.

### 6-3. 생성 후 검증

```bash
ls -l affiliate-site/public/images/<slug>-*.png
```

- 파일이 **100KB 미만이면 거의 빈 그림이다.** 묘사를 사물 중심으로 바꿔 재생성하라
- Replicate 실패(404 `No adapter found` / 429)는 **일시적이다. 같은 Flux 경로로 재시도**한다.
  **어떤 경우에도 Gemini 로 우회하지 않는다**
- 그래도 2장을 못 만들면 **이미지 없이 발행하지 말고** `status: "blocked"` 로 끝낸다

## 7. 게이트 검사 (발행 직전 필수)

```bash
node content-pipeline/gate.js <slug>
npm run build --prefix affiliate-site
```

- **중단(block) 1건이라도 있으면 발행하지 않는다.** 원인을 고쳐서 재시도(2회까지),
  그래도 안 되면 `status: "blocked"` 로 종료한다
- 경고(warn)는 발행을 막지 않는다. 결과에 기록만 한다
- **게이트를 우회하거나 `gate.js` 를 수정해서 통과시키지 않는다. 글을 고쳐서 통과시킨다**
- 빌드가 깨지면 그것도 중단이다

## 8. DRY_RUN 모드

`DRY_RUN=true` 면 **1~3번까지만 수행**하고 4번 이후는 실행하지 않는다.
파일을 만들지도, 고치지도, 커밋하지도 않는다. 무엇을 쓸 계획이었는지만 결과에 담는다.
종료 전 `git status --porcelain` 이 비어 있는지 확인하고, 비어 있지 않으면 `note` 에 적는다.

## 9. 발행 — **네가 하지 않는다**

`git commit` · `git push` · Cloudflare 배포 · IndexNow 제출은 **워크플로가 처리한다**
(`.github/workflows/daily-publish.yml`). 네가 따로 push 하면 워크플로의 커밋 단계와 경쟁한다.

**너는 파일을 만들어 두고 결과 파일을 남기는 데까지만 한다.**

## 10. 기록 — **성패와 무관하게 반드시 한다**

⚠️ 이 단계는 9번의 후속이 아니다. **발행하지 못한 날에도 실행한다.**
막힌 날·슬롯 없던 날·에러 난 날의 기록이 오히려 더 중요하다 —
게이트가 어디서 몇 번 막는지 쌓여야 사전을 고칠 근거가 생긴다.

### 10-1. `EDITORIAL-CALENDAR.md` — **줄을 추가하지 말고 칸만 고쳐라**

**이 파일은 커지면 안 된다.** 네가 매 실행마다 통째로 읽는 파일이고, 읽는 비용이 곧 실행 비용이다.
하루 2.6KB 씩 늘리면 한 달 만에 3배가 된다(딜픽 실측).

발행에 성공했을 때만 해당한다. 그 주차 표의 슬롯 상태를 `🔴` → `✅` 로 **치환**한다.

- ✅ 기존 셀 값 교체 (파일 크기 거의 안 늘어남)
- ❌ 새 줄·새 문단·새 섹션 추가 금지
- ❌ 「발행 기록」 표를 다시 만들지 마라 — 아카이브로 옮겼다
- 막혔거나 슬롯이 없었으면 캘린더는 **건드리지 마라** (다음 날 다시 시도해야 하므로 `🔴` 유지)

### 10-2. `EDITORIAL-CALENDAR-ARCHIVE.md` — 상세 기록은 여기에

파일 **맨 끝** 「## 발행 이력」 섹션에 한 항목을 append 한다.
여기는 네가 읽지 않는 파일이라 길어져도 실행 비용에 영향이 없다.

발행 성공:

```markdown
- **YYYY-MM-DD** ✅ `<slug>` — <mainKeyword>(네이버 볼륨/Google 경쟁). <각도·선정 근거·차별화 데이터 2~3문장>.
  게이트 <통과/경고 N건>.
```

발행 못 함 — **이쪽을 더 구체적으로 적어라. 나중에 원인을 고칠 근거가 된다:**

```markdown
- **YYYY-MM-DD** 🟡 보류 `<slug>` — <mainKeyword>. 게이트 #N <이름> 위반: <검출 내용 그대로>.
  <고치려고 시도한 것과 왜 실패했는지>.
- **YYYY-MM-DD** ⚪️ 슬롯없음 — <어떤 슬롯을 검토했고 왜 못 썼는지>.
- **YYYY-MM-DD** 🔴 에러 — <어느 단계에서 무엇이 깨졌는지. 에러 메시지 원문 포함>.
```

기존 항목의 서술 형식·톤을 따르되, **한 항목 5줄을 넘기지 마라.**

## 결과 파일 (반드시 마지막에)

작업 성패와 무관하게 **`auto-publish-result.json`** 을 repo 루트에 쓴다. 이게 Telegram 알림의 원본이다.

```json
{
  "status": "published | blocked | no_slot | frozen | error",
  "dry_run": true,
  "slug": "bottle-cleanser-2026",
  "mainKeyword": "젖병 세정제",
  "volume": 3250,
  "competition": "MID(63)",
  "category": "신생아",
  "url": "https://babygrade.kr/bottle-cleanser-2026/",
  "blocked_gates": [{ "n": 3, "name": "의약품 효능(식약처)", "detail": "…" }],
  "warnings": [{ "n": 11, "name": "구조", "detail": "표 1 < 2" }],
  "note": "사람이 읽을 한 줄 요약. 폐기한 후보와 사유가 있으면 여기에.",
  "note_full": "긴 근거는 여기에 (알림에는 안 나가고 로그로만 남는다)"
}
```

- 미사용 필드는 `null` 로 둔다
- **`blocked_gates`·`warnings` 에는 `gate.js` 가 실제로 출력한 항목만 넣는다.**
  네 판단·관찰·참고사항은 전부 `note` 에 넣어라. 게이트 번호 없는 항목을 warnings 에 넣지 마라
- **`note` 는 3문장 이내.** Telegram 으로 폰에 뜨는 글이다. 길면 안 읽힌다
- `status: "error"` 면 `note` 에 무엇이 어디서 깨졌는지 적는다

## 절대 규칙

1. **사람에게 되묻지 않는다.** 애매하면 보수적인 쪽(발행 안 함)을 택하고 사유를 `note` 에 남긴다
2. **운영 위반 위험이 있으면 발행보다 중단이 낫다.** 파트너스 계정 정지가 하루치 글보다 훨씬 비싸다
3. **0편으로 끝나도 된다.** 억지로 채우지 않는다. 하루 2편은 어떤 경우에도 쓰지 않는다
4. 작업 범위는 **이 repo 안**으로 제한한다
5. 게이트를 우회하거나 `gate.js` 를 수정해서 통과시키지 않는다. 글을 고쳐서 통과시킨다
6. **이미지에 Gemini 를 쓰지 않는다.** Flux 실패는 같은 Flux 경로로 재시도한다
